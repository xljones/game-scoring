# game-scoring

Count up or down to game score goal. Built using Next.js & Tailwind

Live demo: https://xljones.github.io/game-scoring

## Development

`make install` to build the Docker container for the first time, or after a new npm addition
`make run` to run the hot-reloading server locally
`make build` to produce an output static bundle to release
`make deploy` to deploy to the `gh-pages` branch
